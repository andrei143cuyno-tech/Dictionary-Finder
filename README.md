SPECIAL INSTRUCTIONS
====================

1. Make sure you have an active internet connection because the application retrieves dictionary data from an online API.

2. Keep the project files in the same project folder.

3. Open the project folder using Visual Studio Code.

4. It is recommended to use the Live Server extension in Visual Studio Code.

5. Right-click "index.html" and select "Open with Live Server".

6. Click the "Open Dictionary" or "Try the Dictionary" button to access the dictionary search page.

7. Enter an English word in the search box and click "Search".

Example words:
hello
computer
beautiful
programming
